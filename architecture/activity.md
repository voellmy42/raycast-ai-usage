# Local activity and quota forecasting

Approved 2026-09-28. Read local Codex sessions (including archived sessions) and Claude project JSONL files only to extract allowlisted timestamps, model IDs, token counters, and hashed event IDs. Never persist or display conversation content. This is a narrow exception to the older blanket restriction on opening transcript files in provider SOPs; quota authentication remains unchanged.

Activity is device-local and not attributed to the signed-in account. Codex input includes cached input; reasoning is already part of output. Claude input is the sum of fresh input, cache read, and cache creation; cache creation subcategories are not added a second time. Deduplicate Claude message IDs across streaming records using the most complete coherent reported snapshot (highest output, then input), without mixing corrected cache categories; deduplicate Codex cumulative observations by session and cumulative counters. Do not count inherited initial cumulative totals: use last-token usage for the first observation. Counter decreases start a new baseline. Unknown or missing counters are skipped and reported, never treated as known zero.

Cache only normalized records and source stat signatures keyed by hashed paths. Reparse changed files (including truncations), preserving deduplication; never follow symlink directories/files. Retain 90 calendar days. Bound files, bytes, and events; surface partial import and unavailable directories. A missing or unreadable source must not make cached history appear complete. Gaps in local records do not prove zero account activity.

Quota history is stored separately as atomic immutable observations partitioned by verified Codex identity or Claude snapshot source, with 90-day retention. Record only fresh, successful provider observations and never attach historical transcript quota records to a current account. Forecast each quota window/reset separately from percentage-point consumption, using at least three observations over ten minutes, fresh within five minutes, without gaps above thirty minutes or falling percentages. Use at most the latest two hours. Flat consumption has no finite exhaustion estimate. Report conditional estimates, not statistical confidence or guaranteed exhaustion.

Model comparisons describe token activity and explicitly reported model quotas. Token totals do not establish model efficiency or attributable subscription consumption. Model quota attribution remains unavailable when observations span mixed models or unobserved activity.
