# Menu-bar personalization design

Approved in chat on 2026-09-28.

Dashboard actions pin a provider quota window or select that provider's automatic lowest remaining quota. Default remains automatic Codex. Persist the provider and optional window ID in LocalStorage. Pinning shows the menu and relaunches it after saving.

Extension preferences choose compact percentage or detailed provider/percentage/reset countdown, and individually hide providers from both surfaces. Hidden providers are not read. Keep an accessible preferences action when all are hidden. A hidden selected provider or missing pinned window displays unavailable without silently selecting another quota.

Expired and unknown readings never imply unused capacity. Stale observations and Claude snapshots remain explicitly identified. Countdown corresponds to the selected quota. Existing menu visibility behavior is preserved.
